## Como executar

1. Na pasta do projeto, execute 'npm install'.
2. Edite `src/utils/chaves.js`, substituindo `COLOQUE_SUA_CHAVE_AQUI` pela chave obtida em https://myprojects.geoapify.com. A constante PRIMEUI_LICENSE será a mesma chave; 
3. Execute `npm run dev` e abra o endereço exibido no terminal.
4. Permita que o navegador acesse a localização. O recurso funciona em localhost ou HTTPS.
